# SILENT CALIBER — راهنمای کامل ساخت APK و اجرا

## ⚠️ خلاصه صادقانه
این پروژه یک **دموی واقعی و قابل‌اجرا** است، نه یک بازی در سطح Call of Duty.
گیم‌پلی (تیراندازی، حرکت، بات، مولتی‌پلیر محلی، گرافیک سه‌بعدی WebGL) واقعاً کار می‌کند،
اما تولید محتوایی مثل COD (تیم بزرگ، گرافیک فوق‌واقع‌گرا، سرورهای جهانی) خارج از توان یک پروژه‌ی تکی است.
این فایل صادقانه دقیقاً همون چیزیه که ساخته شده.

---

## 📦 محتویات پروژه
```
silentcaliber_build/
├── www/                 → کد بازی (HTML/CSS/JS + موتور گرافیکی WebGL اختصاصی)
├── server/               → سرور مولتی‌پلیر LAN/Hotspot (Node.js)
├── config.xml            → تنظیمات اپ اندروید (Cordova)
├── package.json          → تنظیمات پروژه Cordova
└── .github/workflows/    → اسکریپت GitHub Actions که خودش APK می‌سازد
```

## 🚀 روش ساخت APK با گیت‌هاب (بدون نیاز به نصب Android Studio)

1. یک ریپازیتوری جدید در GitHub بسازید (مثلاً `silentcaliber-game`).
2. تمام محتویات این پوشه (`silentcaliber_build`) را داخل ریپو push کنید:
   ```bash
   git init
   git add .
   git commit -m "SILENT CALIBER initial build"
   git branch -M main
   git remote add origin https://github.com/USERNAME/silentcaliber-game.git
   git push -u origin main
   ```
3. وارد تب **Actions** در صفحه ریپازیتوری در GitHub شوید.
4. workflow با نام **"Build SILENT CALIBER APK"** به‌صورت خودکار اجرا می‌شود (چون روی `push` تنظیم شده).
5. بعد از اتمام (چند دقیقه)، پایین صفحه اجرا، بخش **Artifacts** یک فایل به اسم
   `SILENT CALIBER-debug-apk` وجود دارد — آن را دانلود کنید. داخلش فایل `.apk` است.
6. فایل APK را روی گوشی اندروید منتقل و نصب کنید (باید نصب از منابع ناشناس را فعال کنید).

> این APK نسخه Debug است (برای تست). برای انتشار در Google Play باید نسخه Release
> امضا شود که نیاز به یک کلید امضای (keystore) دارد — اگر خواستی مرحله بعد راهنمای
> امضا و ساخت AAB را هم آماده می‌کنم.

## 🎮 اجرای بازی
- از منوی اصلی، **شروع بازی** را بزنید.
- **تمرین با بات**: بلافاصله در یک نقشه شهری آفلاین با ۶ بات دشمن بازی می‌کنید.
- **آنلاین محلی (Hotspot)**: یک نفر باید سرور LAN را اجرا کند (مرحله بعد).

## 📶 راه‌اندازی مولتی‌پلیر Hotspot (تا ۲۰ نفر)

یک نفر (میزبان) باید Node.js را نصب داشته باشد (روی لپ‌تاپ، یا روی گوشی با Termux):

```bash
cd server
npm install
node server.js
```

سرور آدرس IP محلی را در ترمینال چاپ می‌کند، مثلاً:
```
192.168.43.1:8080
```

بقیه بازیکنان باید:
1. به همان Hotspot/Wi-Fi وصل شوند.
2. در اپ SILENT CALIBER: شروع بازی → آنلاین محلی → این IP:Port را در فیلد وارد کنند → دکمه Join.

همه بازیکنان متصل، موقعیت و شلیک یکدیگر را به‌صورت لحظه‌ای می‌بینند.

## 🎨 درباره گرافیک
موتور گرافیکی این پروژه یک **رندرر WebGL اختصاصی** است (نه دانلود‌شده از بازی دیگر) —
شامل نورپردازی جهت‌دار، سایه‌روشن سطوح، مه فاصله‌ای (fog) برای عمق میدان،
و ساخت شهر به‌صورت رویه‌ای (procedural). این سطح گرافیک مناسب یک دموی موبایلی
است، نه سطح استودیوهای AAA — که واقع‌بینانه نیست در این پروژه به آن سطح برسیم.

## 🔧 قابلیت‌های پیاده‌سازی‌شده
- تیراندازی اول‌شخص با ۵ سلاح (ریکویل، اسپرد، ریلود، آمار متفاوت هرکدام)
- حرکت، پرش، خم‌شدن، دویدن
- بات دشمن با هوش ساده (تعقیب + شلیک)
- سیستم HP / Armor / Score / Kill-Death
- نارنجک با آسیب انفجاری
- مینی‌مپ، Kill Feed، Hit Marker
- کنترل لمسی کامل (جوی‌استیک + دکمه‌ها)
- تنظیمات گرافیک/حساسیت/صدا (ذخیره‌شونده)
- مولتی‌پلیر LAN/Hotspot واقعی (تا ۲۰ نفر)
